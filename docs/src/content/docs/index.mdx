## Four ways to trade

<CardGrid>
  <Card title="Copy trading" icon="rocket">
    Mirror a trader's positions on the venue you choose. Sized 1:1, proportional or with your own multiplier.
  </Card>
  <Card title="Delta-Neutral" icon="random">
    Long on one venue, short the same token on another, or hold the token on spot against a perp short. You earn the funding-rate spread.
  </Card>
  <Card title="Pair Trade" icon="list-format">
    Several legs at once: long or short, any token, any venue. With a long/short ratio and an optional rebalance.
  </Card>
  <Card title="Trade" icon="pencil">
    Place and manage your own orders on any linked venue: market, limit, TWAP, chase or scale, with TP/SL levels.
  </Card>
</CardGrid>

<CardGrid>
  <Card title="Non-custodial" icon="approve-check">
    Mimiq never holds your funds. You connect API keys that can trade, not withdraw.
  </Card>
  <Card title="Closed beta" icon="information">
    Mimiq is in closed beta and invite-only. You need an invite code to use the bot. No code yet? Join the waitlist in the bot.
  </Card>
</CardGrid>
